Task 1: While Loop & Control Statements – Number Guessing Game
Objective

The first task is to create a simple number guessing game using a while loop.

The program generates a random number between 1 and 10, and the user is given a maximum of three attempts to guess the correct number.

Concepts Used
While loop
Random number generation
Conditional statements
Continue statement
Break statement
Else statement
User input
Logical decision-making
Program Functionality

The program asks the user to guess a number between 1 and 10.

For every guess, the program checks whether:

The entered number is within the valid range.
The guess is greater than the secret number.
The guess is lower than the secret number.
The guess is equal to the secret number.

If the user enters a number outside the range of 1 to 10, the program informs the user and continues the game.

If the user guesses the correct number, the program displays a congratulatory message and ends the game.

If the user uses all three attempts without guessing correctly, the program displays a "Better luck next time!" message.

Learning Outcome

This task helps in understanding iterative execution and the practical use of control statements such as break, continue, and else.

Task 2: For Loop – Multiplication Table Generator
Objective

The second task is to create a multiplication table for a number entered by the user.

The multiplication table is generated from 1 to 10 using a for loop and the range function.

Concepts Used
For loop
Range function
User input
Multiplication
Iteration
Formatted output
Program Functionality

The program asks the user to enter a number.

It then performs multiplication for the numbers from 1 to 10 and displays each result in a multiplication-table format.

For example, if the user enters 5, the program generates the multiplication table of 5 from 1 to 10.

Learning Outcome

This task provides an understanding of for-loop iteration, the range function, sequence generation, and basic calculations using Python.

Task 3: Function – BMI Calculator
Objective

The third task is to create a BMI calculator using a Python function.

The function accepts weight in kilograms and height in meters and calculates the Body Mass Index.

BMI Formula

BMI is calculated using:

BMI = Weight (kg) / [Height (m)]²

Concepts Used
Function creation
Function parameters
Return value
User input
Mathematical calculation
Formatted output
Program Functionality

The program asks the user to enter:

Weight in kilograms
Height in meters

The entered values are passed to the BMI calculation function.

The function calculates the BMI and returns the result.

The calculated BMI is then displayed to the user with two decimal places.

Learning Outcome

This task helps in understanding how to create reusable functions, pass parameters, return values, and perform calculations using user-provided data.
